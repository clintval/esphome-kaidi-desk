# Contributing

## Toolchain

Install [pixi](https://pixi.sh/) and [KiCad 10](https://www.kicad.org/download/).
Pixi provides Python, OpenJDK, build123d and ESPHome, downloads a pinned [Freerouting](https://github.com/freerouting/freerouting) release and [Blender](https://www.blender.org/) (as a Python module, for the renders), and installs [PcbDraw](https://github.com/yaqwsx/PcbDraw) for KiCad's Python.
KiCad comes from its own installer; on Linux, check the `KICAD_*` paths in `pixi.toml`.

## Firmware

Compile the example against the component in this checkout:

```bash
pixi run compile
```

Build the prebuilt firmware and its browser installer into `.build/site`:

```bash
pixi run site
```

Publishing a GitHub release named for a version, such as `0.1.0`, builds that version and puts the installer on GitHub Pages.

## Hardware

Everything in `hardware/` and the images in `docs/` are generated by the scripts in `scripts/`:

```bash
pixi run hardware    # schematic, footprints, PCB placement and routing, assembly files, enclosure, renders, protoboard
pixi run check       # ERC, DRC, schematic parity, netlist and protoboard layout
```

Smaller steps are available too: `schematic`, `footprints`, `pcb`, `fab`, `enclosure`, `renders` and `protoboard`.\
List them with `pixi task list`.

## Mandatory Pre-submission Checks

All must pass before a change is submitted:

```bash
pixi run fmt-check
pixi run lint
pixi run compile
pixi run check
```
