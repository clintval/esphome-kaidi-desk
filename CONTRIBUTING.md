# Contributing

## Toolchain

Install [ESPHome](https://esphome.io/guides/installing_esphome.html), for example with `pip install esphome` or `brew install esphome`.

## Building

Compile the example against the component in this checkout:

```bash
mkdir -p .build
printf 'wifi_ssid: "ssid"\nwifi_password: "password1"\n' > .build/secrets.yaml
sed 's#source: github://clintval/esphome-kaidi-desk@main#source: {type: local, path: ../components}#' \
    example/kaidi-desk.yaml > .build/kaidi-desk.yaml
esphome compile .build/kaidi-desk.yaml
```

## Hardware

The KiCad project in `hardware/` is generated by the scripts in `scripts/`, run with KiCad's Python:

```bash
KPY=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
python3 scripts/make_schematic.py hardware/kaidi-desk.kicad_sch
python3 scripts/make_footprints.py hardware/kaidi.pretty
python3 scripts/make_models.py hardware/kaidi.3dshapes
$KPY scripts/make_pcb.py hardware/kaidi-desk.kicad_sch hardware/kaidi-desk.kicad_pcb
$KPY scripts/route_pcb.py hardware/kaidi-desk.kicad_pcb freerouting-2.5.0.jar "$(brew --prefix openjdk)/bin/java"
python3 scripts/render_schematic.py
```

## Mandatory Pre-submission Checks

The example must compile, as in CI:

```bash
esphome compile .build/kaidi-desk.yaml
```

## Board Illustration

The README's board drawing comes from [PcbDraw](https://github.com/yaqwsx/PcbDraw), installed into KiCad's Python, with part drawings from `scripts/make_pcbdraw_parts.py`:

```bash
python3 scripts/make_pcbdraw_parts.py hardware/pcbdraw
PYTHONPATH=~/Library/Python/3.9/lib/python/site-packages \
    /Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 \
    -m pcbdraw.ui plot --style set-blue-enig --libs "$PWD/hardware/pcbdraw,KiCAD-base" \
    --resistor-values R1:1k,R2:1k,R3:10k,R4:10k,R5:100k,R6:100k,R7:10k,R8:15k,R9:10k,R10:15k \
    hardware/kaidi-desk.kicad_pcb docs/board.svg
```

## Protoboard Guide

The rev 4 build guide is modeled in KiCad from the layout in `scripts/protoboard.py`, drawn by PcbDraw, then labeled:

```bash
python3 scripts/protoboard.py
KPY=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
VALUES=$($KPY scripts/make_protoboard.py hardware/proto | tail -1)
PYTHONPATH=~/Library/Python/3.9/lib/python/site-packages $KPY -m pcbdraw.ui plot \
    --style hardware/proto/eplzon.json --libs "$PWD/hardware/proto/art,KiCAD-base" \
    --resistor-values "$VALUES" hardware/proto/protoboard.kicad_pcb /tmp/protoboard.svg
python3 scripts/annotate_protoboard.py /tmp/protoboard.svg docs/protoboard.svg
```
