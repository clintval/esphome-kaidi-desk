# Contributing

## Toolchain

Install [pixi](https://pixi.sh/) and [KiCad 10](https://www.kicad.org/download/).
Pixi provides Python, OpenJDK, build123d and ESPHome, downloads a pinned [Freerouting](https://github.com/freerouting/freerouting) release and installs [PcbDraw](https://github.com/yaqwsx/PcbDraw) for KiCad's Python.
KiCad comes from its own installer; on Linux, check the `KICAD_*` paths in `pixi.toml`.

## Firmware

Compile the example against the component in this checkout:

```bash
pixi run compile
```

## Hardware

Everything in `hardware/` and the images in `docs/` are generated by the scripts in `scripts/`:

```bash
pixi run hardware    # schematic, footprints, PCB placement and routing, Gerbers, art, enclosure, protoboard
pixi run check       # ERC, DRC, schematic parity, netlist and protoboard layout
```

Smaller steps are available too: `schematic`, `footprints`, `pcb`, `fab`, `art`, `enclosure` and `protoboard`.
List them with `pixi task list`.

## Mandatory Pre-submission Checks

All must pass before a change is submitted:

```bash
pixi run fmt-check
pixi run lint
pixi run compile
pixi run check
```
